# Household Furniture PNG Niche — 2026-08-28

## Decision

Candidate recommendation: **compact rolling kitchen island cart with one open shelf, one drawer, and a clear worktop**, rendered as a single unbranded isolated object for transparent PNG compositing.

The buyer job is a drop-in furniture element for small-kitchen organization articles, apartment layout mockups, renovation and storage content, product comparison pages, and home-planning compositions. It is more useful than a generic chair or table because the object communicates a specific function: movable prep/storage furniture for constrained kitchens.

## Format fit

PNG is appropriate because the buyer may place the isolated furniture object into a room layout, catalog composition, article illustration, or before/after design visual. The object must be a complete silhouette with a clean hard edge, no room background, no brand, no text, no measurement labels, no people, and no manufacturer-specific design.

The object is deliberately not a full room scene. A room scene belongs to the JPEG route. PNG is used only for the compositing-ready furniture component.

## Quality and risk controls

The preview should use a neutral white source background when required by the renderer, with the final alpha created only by the isolated BiRefNet route. The object must have four visible casters, stable proportions, a complete worktop, one drawer, one open shelf, and clear separation between rails and background. Reject if wheels merge into the shelf, handles duplicate, thin rails break, alpha creates a halo, or the object becomes a generic cabinet.

Do not describe the asset as a real product, certified furniture, a specific brand, a safety-rated kitchen unit, or a dimensionally accurate design. Use generic functional language only.
